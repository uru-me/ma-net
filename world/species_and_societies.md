# 主要13種族の社会形態一覧（世界観備忘録）
各種族の「社会組織の形態（国家かそれ以外か）」の定義。

## 📊 種族と社会形態マトリクス

| 種族名 | 社会形態の分類 | 規模感・具体的な組織の特徴 | 試験における一般的な傾向 |
| :--- | :--- | :--- | :--- |
| **人間** | **国家（王国・帝国）** | 封建制の巨大国家。数万人〜数百万人規模。法と組織で統治。 | 魔法の規格化・システム化に優れる。アカデミー免除組や組織戦の主軸。 |
| **エルフ** | **国家（王国・神聖国）** | 結界に守られた森の王国。長命な女王や長老会による中央集権。 | 高い魔力適性と洗練された古代魔法。筆記・実技ともに高水準。 |
| **ドワーフ** | **国家（山岳王国・都市国家）** | 地下や山岳の頑強な城塞都市。職人ギルド連合や王が統治。 | 魔導工学や付与魔術に一日の長あり。3次試験（城塞攻略）での兵器運用に強み。 |
| **魔人** | **国家（魔王国・帝国）** | 魔界や暗黒大陸の軍事国家。圧倒的な「魔王」による絶対恐怖支配。 | 強大な個の魔法力。価値観が異質なため、他受験者との協調性は皆無。 |
| **獣人** | **国家 または 集落** | 部族連合としての「獣王国」か、種族（狼、虎など）ごとの集落。 | 身体能力を活かした近接魔導。野生派と国費留学生（エリート）に二分される。 |
| **アンデッド** | **国家を持たない**<br>（魔王軍のいち勢力・墓所） | 基本は自立社会を持たない。例外的に「不死者の王（リッチ）」が隔離された死者の街をひっそり統治。 | もし受験者にいれば「魔法の深淵を求め続ける元人間の学者」等。会場が凍りつく枠。 |
| **オーク** | **集落（部族）** | 強い戦首（オークキング等）が率いる、数〜数百人規模の戦闘キャンプ。 | 基本は脳筋の蛮族扱い。筆記（1次）を抜けてきた奴は例外なく化け物。 |
| **ゴブリン** | **集落（群れ・巣穴）** | 洞窟などを拠点にする、繁殖力任せの野生的な群れ。統率力は極めて低い。 | 最下層種族。受験すること自体が稀だが、もし来れば「異常に狡猾な変異種」。 |
| **リザードマン** | **集落（湿地部族）** | 湿地や平原に点在する血縁ベースの集落。独自の戦士の掟で動く。 | 耐久力と水辺適性。文字を持たない集落から「国家の作り方を学ぶため」に命をかける熱い枠。 |
| **巨人** | **集落（孤立集落） または 単独** | 希少種ゆえ、人里離れた高山などで数十人規模の小集落を作るか、単独行動。 | 災害・神話級の物理力。数が少なすぎるため、試験会場に現れるだけで注目の的。 |
| **竜人** | **集落（聖域・隠れ里）** | 高峰や竜の巣の周辺にある、少数精鋭の厳かな誇り高き集落（自治区）。 | 畏怖と尊敬の対象。高い魔力と戦闘力を両立する、おのぼり野生派の最強格。 |
| **フェアリー** | **集落（妖精郷）** | 人間には見えない・入れない、気まぐれに楽しむための小規模コミュニティ。 | 小型で高密度な魔力。気まぐれなため、試験のルールを無視しがち。 |
| **精霊?** | **社会を持たない** | 概念や自然そのもの。個々が世界に遍在し、群れや統治の概念はない。 | 社会を持たないため受験者にはならない。魔法師たちの「契約・信仰対象」として登場。 |

## 📌 設定構築用のメモ

### 1. 「国家組」と「集落組」の決定的格差
*   **国家組（人間・エルフ・ドワーフ）**: **文字（記録）**、**大規模農業（蓄え）**、**法（契約）**を持つ。組織的な魔法の運用や、インフラとしての魔術フレームワークの構築が得意。
*   **集落組（リザードマン・オーク等）**: **口承文化**、**狩猟採集（その日暮らし）**、**血縁・力関係**で動く。個々のスペックや野生の勘は凄まじいが、文字が読めない者が多いため、デュモンク王国の1次試験（筆記）が最大の門番となる。

### 2. 試験編におけるドラマへの活かし方
*   1次試験（筆記）の会場では、文字の読めない「集落組」の突然変異の天才たちが、洗練された「国家組」のエリート（アカデミー免除組など）から見下される描写が映える。
*   3次試験（城塞攻略演習）のチーム分け（1チーム4人）の際、強制的に「国家組」と「集落組」が混ざることで、**「高度な戦術理論を押し付けるエリート人間」**と**「野生の勘と圧倒的スペックで強行突破しようとする亜人」**の凸凹な化学反応を描くことができる。
