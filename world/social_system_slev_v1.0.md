# ディモンク王国のスレブ
## 1. スレブ（Slev）の供給源（史実準拠）
ディモンク王国を含む諸国において、歴史的に「人的リソース」として扱われてきた者たちの分類。
- 戦時スレブ（戦争捕虜）: 最大の供給源。人種や民族を問わず、敗戦国の兵や住民がそのまま勝者の「資産」として登録される。
- 負債スレブ: 事業失敗やギャンブルなどで再起不能な負債を抱えた自由民が、返済のために期間付きで身を投じたもの。
- 犯罪スレブ: 重大な犯罪などを犯した者が、処刑の代替として終身労働の義務を課された状態。魔力封じの措置が取られることが多い。
- 専門職スレブ: 敗戦国の医師、技術者、学者、高位魔法師など。法的には「所有物」の扱いだが、その高い専門性ゆえに「家庭教師」や「宮廷顧問」などの高い社会的地位を伴う役職に就くことがある。

## 2. 魔法大国における労働環境
* ホワイトな重労働: 魔法師が「重機」の役割を果たすため、他国のような過酷な肉体労働は少ない。奴隷は「魔法の補助（バッファ）」として扱われる。
* 魔力バッテリー: 才能がある奴隷は、魔石への魔力充填作業に従事させられる。

## 3. ニアの技術革新によるパラダイムシフト
* 物理法則の導入: 支点・力点・作用点などの導入により、魔法を使わずとも「少人数で巨大な力」を生み出せるようになる。
* 魔力効率の劇的向上: 物理法則（アルゴリズム）を用いた術式最適化により、大量の奴隷（外部リソース）が不要になる。
* 経済的解放: 「奴隷を所有・管理するコスト」が「機械・自動化のコスト」を上回り、アドミク王による「市民化（納税サブスク化）」が加速する。

# ディモンク王国の「スレブ制」とリソース近代化

## 1. スレブ（Slev）の定義
この世界において、個人の意思に関わらず「国家や他者の資産」として固定された人的リソースの総称。

* 供給源:
    * 戦争捕虜（主に他国の兵士）
    * 負債による強制就労者
    * 魔導犯罪者（罰として魔力を封じられ、労働に充てられる者）
* 専門職スレブ: 稀に高度な知識を持つ者が含まれるが、基本的には「使い捨ての外部リソース」として扱われる。

## 2. ニアによる「リファクタリング」
ニアはこの「スレブ」という呼称と存在に強い不快感を抱き、技術革新によってこのシステムを物理的に不要（非効率）なものへと追い込んでいく。

* 物理による自動化: 
    「人間をスレブとして使うより、滑車と蒸気（あるいは魔導機関）を使う方が圧倒的に安上がり」という経済的現実を突きつける。
* 人道ではなく効率による解放: 
    アドミク王に「リソースを所有するコスト（管理費）」よりも「自由な市民から税を得るメリット」を説き、法的なOSアップデートを促す。
